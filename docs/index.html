Method and caveats

  • Source: public Jobsuche API of the Bundesagentur für Arbeit, queried daily for 12 analyst search terms. The API's search is fuzzy, so every result is re-classified by title and off-target jobs are dropped.
  • German requirement, ad language and tools come from rule-based text matching on each description. They are indicative, not exact. Only these derived features are stored, never the advert text.
  • Most German job ads don't publish salary, so salary figures cover a small, self-selected subset.
